# SplitXplorer

SplitXplorer splits the VS Code Explorer into named, collapsible sections. By default you get two:

- **Gitacknowledged**: files git does not ignore.
- **Gitignored**: files and folders matched by `.gitignore`.

You can add your own sections and fill them with glob rules or by dragging files in.

## Features

- **Custom sections.** Click the **+** button on any section header to add a section. Choose Gitacknowledged, Gitignored, Blank, or All Files as a starting point, then name it.
- **Rules.** Use **Edit Section Rules** to add glob patterns, add specific files or folders, or remove existing rules.
- **Drag and drop.** Drag files between sections, or drop them in from the built-in Explorer.
- **Item actions.** Right-click an item to move it to another section, also show it in another section, remove it from the current one, reveal it in the Explorer or your OS file manager, or copy its path.
- **Built-in Explorer integration.** Right-click a file in the built-in Explorer and choose **Show in SplitXplorer Section...**. A header action also toggles whether the built-in Explorer hides gitignored files.

Sections are saved per workspace. You can have up to 12.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| `splitXplorer.dragBehavior` | `move` | `move` removes an item from its source section when you drag it to another section. `copy` leaves it in both. |

## Known limitation

VS Code labels sections in the Explorer's right-click menu with fixed names: Gitacknowledged, Gitignored, and Custom Section 1 through 10. Renaming a section changes its header, but not its name in that menu.

## Development

```bash
npm install
npm run compile
npm test
```

Press F5 in VS Code to launch an Extension Development Host. The section views are declared in `package.json`, which is generated by `npm run manifest` from `scripts/manifest.js`. Edit that script instead of editing the views, commands, or menus in `package.json` by hand.

To build a `.vsix` package:

```bash
npx @vscode/vsce package
```
